# WeatherWise

Proiectul este impartit in doua foldere:

- `frontend` - aplicatia React + Vite
- `backend` - serverul API Node.js

## Frontend

```bash
cd frontend
npm run dev
```

## Backend

```bash
cd backend
npm run dev
```

Backend-ul porneste implicit pe `http://localhost:3000`, iar endpoint-ul de test este `GET /api/health`.
